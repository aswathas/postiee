- Platform detection verified against real uname output

Agent skill:

Benchmarks:
- bench/main_test.go produces every number quoted in the README
- Speed: search 145us at 1k posts, 347us at 10k; history 79us; record 1.48ms
- Accuracy: porter stemming, multi-term AND, absent terms, junk-input
  safety, urn/permalink formats

Two real bugs found and fixed while measuring:
- FTSQuery emitted quoted terms whose trailing * did not prefix-match, so
  partial-word search silently returned nothing. The star must sit outside
  the closing quote.
- Member ids and post urns from the live account had leaked into benchmark
  fixtures. Replaced with placeholders before this commit.

README documents the three traps that break naive LinkedIn clients: the post
id lives in a response header rather than the body, person ids are scoped
per app, and urns in paths need full percent-encoding.
